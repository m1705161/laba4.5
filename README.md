# Лаба 4.5 — StarRocks DWH и агент данных (MCP × RAG)

Строим классический DWH-слой на **StarRocks** — `STG → ODS → DM` с **SCD2** — по одной из 4
предметных областей, а поверх — **агента**, который сам решает, куда идти за ответом:
в базу (SQL через **MCP**-инструмент `run_sql`) или в документы (векторный поиск в **Qdrant** + **Ollama**).

Всё поднимается и удаляется прямо в этой лабе (Docker), ничего общего с другими лабами не требуется.

## Две части

| Часть | Что делаем | Скрипты |
|---|---|---|
| **A. DWH** | STG → ODS (+SCD2) → DM, исследование моделей таблиц | `loader.py`, `scd2.py`, `dm.py`, `research.py` |
| **B. Агент** | MCP-сервер `run_sql` + RAG (Qdrant) + LLM (Ollama), 4 режима | `mcp_server.py`, `embed.py`, `agent.py` |

## Требования

- **Docker Desktop** (с поддержкой `host.docker.internal`).
- ~**16 ГБ** места под образы, ~**6 ГБ RAM** (StarRocks + Ollama), ~**3 часа** на прохождение.
- Модель `qwen2.5:1.5b` (~1 ГБ) и эмбеддинги MiniLM (~470 МБ) качаются разово.

## Как запускать

| Система | Гайд |
|---|---|
| **macOS / Linux** | [`guide.md`](guide.md) — полный гайд с объяснениями |
| **Windows** | [`guide-win.md`](guide-win.md) — то же самое, команды под PowerShell |

В обоих гайдах команды готовы для копирования. Свою область подставляешь вместо `oil-gas`.

## Области (варианты)

| Вариант | Область | `--domain` | Факт «…» |
|---|---|---|---|
| 1 | Нефтегаз | `oil-gas` | добыча (скважины) |
| 2 | Металлургия | `metallurgy` | выплавка (печи) |
| 3 | Химтех | `chemical` | выход партии (реакторы) |
| 4 | ИВТ | `cs` | обработка (серверы) |

## Структура репозитория

```
лаба-4.5-starrocks-agent/
├── guide.md            # полный гайд (macOS/Linux)
├── guide-win.md        # гайд под Windows
├── README.md           # этот файл
├── requirements.txt    # зависимости python
├── loader.py           # STG: грузит CSV → stg_*
├── scd2.py             # ODS: dim со SCD2 + факт
├── dm.py               # DM: витрина-агрегат
├── research.py         # исследование моделей таблиц (Dup/PK/Agg)
├── embed.py            # эмбеддинги документов → Qdrant
├── mcp_server.py       # MCP-инструмент run_sql (read-only)
├── mcp_check.py        # проверка инструмента run_sql
├── agent.py            # агент: 4 режима (none/sql/docs/both)
├── data/<область>/     # CSV: dim.csv, changes.csv, fact.csv
└── documents/<область>/# markdown-документы для RAG
```
